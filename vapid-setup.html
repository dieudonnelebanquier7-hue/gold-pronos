Configuration sécurisée des notifications

Cette page génère les clés Web Push directement dans ton navigateur. La clé privée n’est envoyée à aucun serveur par cette page. Tu dois copier les valeurs dans Supabase Secrets.

1. Générer les clés gratuites

Appuie sur le bouton. Garde cette page ouverte jusqu’à ce que les valeurs soient copiées dans Supabase.

VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
VAPID_SUBJECT
https://dieudonnelebanquier7-hue.github.io/gold-pronos/

2. Ajouter les clés dans Supabase

Ouvre Supabase · Edge Function Secrets, puis ajoute les trois noms exactement comme affichés, avec leurs valeurs. Ne mets jamais la clé privée dans GitHub ou dans le code de l’application.

La clé privée reste confidentielle. Ne l’envoie pas dans une conversation ou à une autre personne.

3. Activer l’analyse par trois IA

Crée une clé sur OpenRouter · API Keys, puis ajoute dans Supabase Secrets :

OPENROUTER_API_KEY

Valeur : la clé créée sur OpenRouter. Les appels aux modèles peuvent être payants selon les modèles choisis et le solde du compte.

Facultatif : OPENROUTER_MODELS pour préciser trois modèles séparés par des virgules. Sinon GOLD PRONOS utilise ses modèles par défaut.

Après l’ajout des secrets, reviens dans l’application et active les notifications en arrière-plan depuis ton compte. L’automatisation complète des alertes nécessite encore l’activation du déclencheur serveur.
